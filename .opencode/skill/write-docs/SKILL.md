# Skill: Write Documentation

Use this skill when the user asks to create documentation, user guides, manuals, or FAQs.

## When to use

- "Creame la documentación de X"
- "Necesito una guía para el admin"
- "Generá el manual del profesional"
- "Haceme un FAQ"

## Types of documentation

### 1. Admin Guide (`docs/admin-guide.md`)
- Company setup (name, logo, theme, gym mode)
- Customer management (with/without account, credits)
- Professional management (with credentials, alias)
- Service management (3 modes, modalities)
- Report generation and export
- Holiday management
- Time window configuration

### 2. Professional Guide (`docs/professional-guide.md`)
- Login and portal navigation
- Viewing assigned services
- Marking attendance
- Completing clinical history

### 3. Customer Guide (`docs/customer-guide.md`)
- Viewing available services (calendar)
- Making reservations
- Cancelling reservations
- Viewing credits
- Changing password

### 4. FAQ (`docs/faq.md`)
- Common questions by role
- Troubleshooting guide

## Format

Use Markdown with:
- Clear headings (##, ###)
- Numbered steps for procedures
- Bullet points for lists
- Code blocks for SQL or configuration
- Tables for comparisons
- Bold for important terms
- Links to relevant pages

## Language

Write in Spanish (Argentina) for user-facing documentation.
Technical documentation can be in English.
